# Portfolio Projects — Domain Index

Each file in this list gives the same eight-project progression in a different domain. The skills, the study plan units, and the deliverables are the same in all files. Only the problems, the data, and the tools are different.

Select one domain and do all eight projects in it. Do not mix domains. A reviewer must see one system that grows.

## How to select a domain

- **Select a domain where you want to work.** A hiring manager in that industry reads the portfolio faster when the problems are familiar.
- **Check the data first.** Download the main dataset before you start. If you cannot get it, select a different domain.
- **Regulated domains show more skills.** Healthcare, legal, and security need access control, audit logs, and human approval. These are strong signals for enterprise roles.
- **Consumer domains show scale.** E-commerce, OTT, quick commerce, and travel need high volume, low latency, and a low cost per request. These are strong signals for product company roles.
